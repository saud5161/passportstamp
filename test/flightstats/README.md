# لوحة رحلات مطار الملك خالد الدولي ✈️

صفحة احترافية لعرض جميع رحلات القدوم والمغادرة في مطار الملك خالد الدولي (الرياض)
مع فلاتر: نوع الرحلة (قدوم/مغادرة)، الصالة، الحالة، التاريخ، وبحث نصي.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً من داخل المجلد:

```bash
npx serve .
```

## مصادر البيانات (بالترتيب)
الصفحة تحاول الاتصال بالمصادر التالية تلقائياً، وتنتقل للتالي عند فشل أي منها:

1. **المصدر الرسمي لموقع مطار الملك خالد (kkia.sa)** — مجاني بالكامل، بدون مفتاح، ويحتوي
   على وقت مقدّر حقيقي منفصل عن الوقت المجدول بالإضافة لحالات فعلية (صعود/إغلاق بوابة/استلام حقائب).
   هذا هو المصدر الافتراضي ولا يحتاج أي إعداد.
2. **AeroDataBox عبر RapidAPI** — مصدر احتياطي فقط إن تعطّل الموقع الرسمي مؤقتاً. يتطلب مفتاحاً
   في `assets/js/config.js` (اختياري تماماً الآن).
3. **بيانات تجريبية** — تظهر تلقائياً فقط إذا فشل المصدران أعلاه معاً (مثلاً عند انقطاع الإنترنت).

الشارة أعلى الصفحة توضّح دائماً أي مصدر يُستخدم حالياً.

## البنية
```
index.html              الصفحة الرئيسية
assets/css/style.css    التصميم
assets/js/config.js     إعدادات المطار ومفتاح الـ API
assets/js/app.js        منطق الجلب والفلترة والعرض
```
